# Localtime zone Patch 0.1.4

Adds compatibility with **EveJS 261115.2 on Windows Native** using the
build-3396210 client.

- Supports the exact reviewed login source, including the new upstream staff
  server-health payload, while retaining native authentication, Placebo
  signatures, framing, encryption and SSO.
- Keeps the Neocom clock and date/UTC-offset tooltip tied to each player's own
  PC timezone and daylight saving settings. Server time and normal Calendar
  behavior stay unchanged.
- Includes matching Launcher update metadata for the package's declared EveJS
  versions, verified through the actual updater.

Windows Native qualification passed individual enabled/disabled, Calendar,
cleanup and reconnect controls, combined-mod clock/hook/shared-menu coexistence,
and a same-world retail-client reconnect. Existing reviewed version declarations
are retained. **No new Docker/Linux runtime or other client-build qualification
is claimed.**

## Install or update

Use **Launcher -> Mods** to install the update. For a fresh installation, use
**Add ZIP** with `EveJS-Localtime-zone-Patch-0.1.4.zip`, then enable the mod.
Restart Game and reconnect each client. No player-data migration, menu or
timezone configuration is needed.
