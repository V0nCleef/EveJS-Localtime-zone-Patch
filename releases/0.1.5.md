# Localtime zone Patch 0.1.5

Adds reviewed **EveJS 261125.3 and 261126.2 Native** compatibility declarations
for the **EVE 24.02 / build-3724492 Windows client**. This resolves the Launcher's
unsupported-version warning for those releases.

The Neocom clock still uses each player's own computer timezone and daylight
saving settings. Server time, the Calendar action and reconnect cleanup keep
their existing behavior. All earlier supported EveJS versions are retained;
the exact-source guards are unchanged.

Update through **Launcher -> Mods**, restart Game and reconnect each client.
No player-data migration or timezone configuration is required.

Qualification covers Windows Native packet checks and offline execution of the
exact client login/clock bytecode, with the older build retained as a control.
Rendered-client/network and Linux/Proton runtime qualification remain pending.
Docker support is not added. See VERIFICATION.md for the boundaries.
