metadata, version diagnostics and documentation. Each client keeps its own
Windows local time and daylight-saving behaviour. Server UTC, simulation time

has no saved settings to migrate. Earlier 0.1.0 and initial 0.1.1 packages without
an `updates` declaration need the one-time corrected ZIP reinstall described in
[RELEASING.md](https://github.com/V0nCleef/EveJS-Localtime-zone-Patch/blob/v0.1.2/RELEASING.md).
